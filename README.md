## GitHub Pages

This is a static website. No installation, build process, or API key is required.

Publish the repository with **Settings → Pages → Deploy from a branch → main → / (root)**.
The entry point is `index.html`; `.nojekyll` preserves the static assets as supplied.
For a user website, name the repository `<username>.github.io`.

The portfolio retains the existing search-engine noindex preference. Its pages are publicly viewable by direct link.

## Local preview

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`.
